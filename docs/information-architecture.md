# Information Architecture

## Public navigation
- Home
- Work
- Services
- About
- Contact

## Public content model
- Hero with founder positioning and CTA.
- Featured case studies.
- Services overview.
- Founder biography.
- Process/approach.
- Contact CTA.

## Work directory model
- Project list grid.
- Category filter chips.
- Search by title or summary.
- Featured projects prioritized.
- Empty state when no results.

## Case study model
- Title, slug, summary, category.
- Cover and gallery images.
- Problem, approach, features, results.
- Live URL and repository link.
- SEO metadata.

## Admin navigation
- Overview
- Projects
- New project
- Settings
- Logout / sign out

## Project workflow
- Draft: saved privately.
- Publish: public listing and public detail visible.
- Unpublish: hides public listing and detail.
- Feature: highlights project on the homepage and work directory.
- Delete: requires confirmation and safe cleanup.
