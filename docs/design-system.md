# Design System

## Visual direction
Premium minimal dark-first portfolio with graphite backgrounds, white text, subtle neutrals, and electric blue highlights.

## Tokens
- Background: #111111
- Surface: #171717
- Text: #F5F5F5
- Muted text: #A3A3A3
- Accent: #0096FF
- Border: rgba(255,255,255,0.12)
- Radius: 18px / 24px / 32px
- Shadow: elevated surfaces with soft neutral depth

## Typography
- Sans: Geist, Inter, or Space Grotesk fallback stack.
- Type scale: 12/14/16/18/24/32/48/72.
- Line lengths optimized for readability.

## Layout
- Max content width: 1200px.
- Responsive breakpoints: mobile, tablet, desktop.
- Generous whitespace and strong visual rhythm.

## Components
- Header with top navigation.
- Project cards with consistent aspect ratio and hover state.
- Buttons with clear hierarchy.
- Filters and form inputs in dark theme.
- Status pills for published, draft, featured states.

## Interaction
- Purposeful motion and reduced-motion handling.
- Hover and focus states should be visible and accessible.
- Avoid decorative motion that slows down content exploration.
